# 외주인건비 대시보드 (AS · 김해공장)

ERP에서 내려받은 협력업체 외주인건비 입고 내역(xls)을 집계해 GitHub Pages로 보여주는 정적 대시보드입니다.
기존 엑셀 `월간 인건비 보고서`의 파워쿼리·피벗 규칙을 그대로 따르므로 엑셀 보고서와 같은 값이 나옵니다.

- 사이트: https://andaiga-create.github.io/outsource-labor-cost/
- 저장소: https://github.com/andaiga-create/outsource-labor-cost

---

## 1. 매월 데이터 업데이트 절차

### ① 파일 넣기
지금까지 하던 대로 ERP 자료를 아래 폴더에 넣습니다. 파일명은 자유입니다. (폴더 안의 모든 xls 를 읽습니다)

| 폴더 | 내용 |
|---|---|
| `원본_AS/` | AS 월별 파일 (전 업체 포함, 예: `2026.11_AS.xls`) — 폴더에 바로 넣기 |
| `원본_김해공장/` | 김해공장 업체별 월 파일 (예: `범양마린_2026.11_김해공장.xls`) — 폴더에 바로 넣기 |
| `원본_AS/2024년까지/`, `원본_김해공장/2024년까지/` | 과거 자료 (수정 불필요, 과거 규칙 적용) |

> 같은 달 자료를 두 번 넣으면 **중복 합산**됩니다. 서로 다른 파일에 같은 전표가 있으면 변환 화면에 `[주의] 중복 투입 의심` 이 표시됩니다.
> 업체가 추가되거나 열이 늘어나도 그대로 넣으면 됩니다. 열은 이름으로 찾습니다.

### ② `update.bat` 더블클릭
1. xls 변환 → `docs/data.json` 생성 + **검증용 엑셀 `엑셀보고서/외주인건비_보고서_YYYY.MM.xlsx`** 생성 (아래 참고)
2. `git commit`
3. `git push` (GitHub 업로드)

"Done" 이 나오면 완료입니다. **1~2분 뒤** 사이트에서 `Ctrl+F5`로 새로고침하세요.
처음 실행할 때는 이 폴더를 GitHub 저장소에 자동으로 연결합니다.

> 변환 결과만 점검하려면 명령 프롬프트에서 `update.bat build` (업로드 생략)

---

### 검증용 엑셀 보고서
`update.bat` 을 실행할 때마다 `엑셀보고서/외주인건비_보고서_YYYY.MM.xlsx` 가 새로 만들어집니다. (GitHub 에는 올라가지 않음)

| 시트 | 내용 |
|---|---|
| 대시보드 | 올해 누계·목표 대비·전년 동기·매출 대비 + 차트 (연도별, 월별, 누적, 장비, 호선, 업체, 선종) |
| 집계 | 연도별·월별·TOP 표. **모든 금액이 RAW_통합 을 SUMIFS 로 다시 계산하는 수식**이라 직접 검증 가능 |
| RAW_통합 | 대시보드에 들어간 전체 행 + 원본 파일명 |
| 제외내역 | 규칙으로 빠진 행과 사유 (CP/CQ 아님, LWN-, 프로젝트코드 없음) |

### 기존 `월간 인건비 보고서` 계속 쓰기
`update.bat` 은 `엑셀보고서/RAW/김해공장+AS RAW.xlsx` 도 함께 만듭니다. 기존 보고서의 파워쿼리가 읽던 RAW 쿼리 파일 4개를 합친 것과 같은 형식(시트 `sheet1`, 12개 열, 1단계 통과 행 전체)입니다.

**처음 한 번만** 기존 보고서의 쿼리 경로를 이 폴더로 바꿉니다.
1. 보고서를 새 달 이름으로 복사해서 엽니다.
2. `데이터` → `데이터 가져오기` → `데이터 원본 설정`
3. 목록의 `Z:\D-0_자료_부서보고\월간 인건비 보고서\김해공장+AS RAW DATA` 와 `\\tf2f-nas\...\김해공장+AS RAW DATA` 를 각각 선택 → `원본 변경` → `...\pjt_9 (인건비 보고)\엑셀보고서\RAW` 폴더 지정
4. `모두 새로 고침` → RAW_통합·피벗·차트 갱신

이후 매월: `update.bat` 실행 → 보고서를 새 달 이름으로 저장 → `모두 새로 고침` → 날짜(슬라이서) 변경.
> `RAW` 폴더에는 이 파일 하나만 두세요. 쿼리가 폴더 안의 모든 파일을 합칩니다.

> 같은 달 보고서가 엑셀에서 열려 있으면 저장되지 않습니다(경고만 표시, 웹 업데이트는 계속 진행).

## 2. 집계 규칙 (엑셀 파워쿼리와 동일)

| 단계 | 규칙 |
|---|---|
| `2024년까지` 하위 폴더 | `거래처` 가 빈 행(합계·일계 행) 제외 |
| `원본_AS` 바로 안 (2025~) | `거래처명` 이 있고 `품목번호` 가 정확히 `CP` 또는 `CQ` 인 행 |
| `원본_김해공장` 바로 안 (2025~) | `품목번호` 가 정확히 `CP` 또는 `CQ` 인 행 |
| 공통 (보고서 RAW_통합) | `품목번호` 에 CP/CQ 포함, `프로젝트코드` 에 `LWN-` 미포함 (코드가 빈 행도 제외) |
| 파생 | 프로젝트코드 `고객-호선-장비-선종` 분해. 끝 2자리 C1·C2 = 상선, S1 = 특수선, 그 외 = **유상** |

- 대시보드 기본값은 엑셀 피벗과 같게 **유상 제외(상선·특수선)** 입니다. 왼쪽 `선종` 에서 유상을 켜면 포함됩니다.
- `선종별` 도넛은 엑셀과 같이 선종 필터와 무관하게 세 가지를 모두 보여줍니다.
- 금액은 `공급가`(부가세 제외), 원 단위 반올림입니다.

원본 폴더의 위치·이름을 바꾸려면 `scripts/build_data.py` 맨 위 `SOURCES` 를 함께 고칩니다.

## 3. 매출·목표 설정 (`docs/settings.json`)

```json
{
  "revenue": { "2025": 17919000000, "2026": 24497611317 },
  "target":  { "2026": 220000000 }
}
```

| 항목 | 설명 |
|---|---|
| `revenue` | 연도별 매출액(원). 매출 대비 비율 계산에 사용. 새 연도가 되면 추가 |
| `target` | 연간 외주인건비 목표(원). 목표 대비 % 와 누적 차트 목표선에 사용 |

수정 후 `update.bat` 을 실행하면 반영됩니다.

## 4. 폴더 구조

```
README.md
update.bat              # 변환 + 업로드 (더블클릭)
scripts/build_data.py   # xls → docs/data.json
scripts/build_excel.py  # 검증용 엑셀 보고서
docs/                   # 웹사이트 (GitHub Pages 가 이 폴더를 게시)
  index.html, style.css, app.js
  data.json             #   변환 결과(집계값)
  settings.json         #   매출·목표
원본_AS/, 원본_김해공장/   # 원본 xls (PC 에만 보관, 업로드 안 됨)
엑셀보고서/               # 자동 생성 검증 보고서 + 기존 엑셀 보고서·쿼리 (업로드 안 됨)
```

- 원본 xls·xlsx 는 `.gitignore` 로 제외되어 GitHub 에 올라가지 않습니다. 사이트에는 집계값만 공개됩니다.
- GitHub Pages 설정: Settings → Pages → Branch `main` / 폴더 `/docs`.
